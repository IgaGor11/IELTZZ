# WordFlow500 2.0 — архитектура (проект)

UX-цель: минимализм + тёмная тема + управление одной рукой; «zero cognitive noise».
База — текущая кодовая база WordFlow500 (SwiftUI, iOS 17+, Observation, UserDefaults).

---

## 1. Ключевое решение: доступ к AI из РФ без VPN

Прямые вызовы внешних LLM из РФ не работают:

| Провайдер | Из РФ (проверено) | Через Cloudflare Worker |
|---|---|---|
| Gemini API | timeout (заблокирован) | доступен |
| OpenRouter (Nemotron `:free`, 1M ctx) | 403 (гео-блок CF) | доступен |
| Groq | 403 | доступен |
| DeepSeek | 401 (сервер отвечает) | доступен |

Вывод: **телефон НИКОГДА не ходит к LLM напрямую.**

Схема:

```
[iPhone]  --HTTPS-->  [Cloudflare Worker: /api/ai/*]  --fetch-->  [Gemini | OpenRouter | Groq]
   (только свой воркер, без ключей LLM в приложении)
```

- Воркер живёт в дата-центре Cloudflare → к ним доступен без VPN.
- Ключи LLM хранятся только как secrets воркера (`GEMINI_API_KEY`, `OPENROUTER_API_KEY`, `GROQ_API_KEY`).
- Приложение ходит на эндпоинты своего воркера (`lifeos.pifagoryy.workers.dev/api/ai/*`) с токеном доступа.
- Каскад провайдеров: Groq (самый быстрый/дешёвый) → Gemini flash (free) → OpenRouter `:free`. Уже реализовано в `bot/src/llm.ts` — переиспользуем.

### Почему не встроить в существующий lifeos-воркер полностью
Готовый `llm.ts` годится как образец каскада, но он завязан на телеграм-бота, его cron и лимиты. Для iOS-приложения выделяем **отдельный маршрут `/api/ai/*`** в том же воркере (бесплатный план Worker позволяет), с отдельным служебным токеном и rate-limit. Если в будущем App Store — маршрут выносится в отдельный worker `wordflow-ai`.

## 2. Слои приложения

```
App (AppCoordinator)
 └─ AI (новое)
 │   ├─ AIAPIClient        → HTTP к /api/ai/* (URLSession, async/await)
 │   ├─ AICache            → on-device кэш результатов (SwiftData/SQLite)
 │   ├─ AIEnricher         → enrich/синонимы/коллокации/контекст (пакетно)
 │   ├─ AIEvaluator        → проверка примеров, Writing/Speaking оценка
 │   └─ AIBudget           → токен-бюджет, кэш-политика, офлайн-режим
 ├─ Domain
 │   ├─ SRS v2 (SM-2 eases + AI-вес сложности)
 │   ├─ Mastery (уровни 0–10, Surprise Test)
 │   ├─ DifficultyModel   → per-word сложность (оценка ИИ + статистика)
 │   └─ ForgettingCurve   → временной ряд попыток
 ├─ Stores (SwiftData, миграция из UserDefaults)
 └─ Views (Study v2, Words, Statistics v2, Boosters)
```

Правило: **приложение полностью работает офлайн** (база из 500 слов уже есть). AI — опциональный усилитель; недоступность сети/бюджета → деградация на данные кэша/сидов.

## 3. Данные: SwiftData + миграция

Сейчас: весь JSON в UserDefaults (никчемно для попыток/кривой забывания). 2.0 переводит на **SwiftData** (`@Model`), за схемой — миграция с `vocabulary.words.v1`, `mistakes.*`, профилей.

### Модели (эволюция)
```swift
@Model VocabularyWord {
  id, word, listNumber, translation           // как сейчас
  level: Int                                  // было 0–5 → стало 0–10
  synonyms: [String]          // AI: significant → important, notable, …
  collocations: [String]      // AI: significant impact / difference / …
  registerTags: [String]      // Academic | Formal | Informal
  topic: String?              // IELTS-тема: Environment, Education…
  aiExamples: [String]        // AI-контекст (Writing Task 2 темы)
  isAIEnriched: Bool
  // SRS v2
  easeFactor: Double          // SM-2
  intervalDays: Int
  repetitions: Int
  lapses: Int
  // статистика
  attempts: [AttemptRecord]   // {at: Date, latency: TimeInterval, correct: Bool, mode}
  difficultScore: Double      // от DifficultyModel
  learnerCorrectStreak: Int
  contextSentencesOK: Int     // ИИ подтвердил корректные примеры
  lastSurpriseDate: Date?
}
```

### Батч-апгрейд данных
- level 0–5 → 0–10: `уровень10 = уровень5 * 2`.
- Разовая фоновая догрузка: 500 слов бьём на пачки по 25, `enrich` пакетом (1 запрос на пачку), кэшируем.

## 4. AI-движок (worker + промпты)

### Эндпоинты воркера `/api/ai/*` (реализация по образцу llm.ts)
| Эндпоинт | Что делает | Тело |
|---|---|---|
| `POST /api/ai/enrich` | синонимы+коллокации+регистр+тема, массивом до 25 слов | `{words:[{word,translation}]}` |
| `POST /api/ai/context` | 3 примера по IELTS-теме | `{word, translation}` |
| `POST /api/ai/check-example` | проверить свой пример (грам. + стиль) | `{word, sentence}` |
| `POST /api/ai/writing` | оценка абзаца по IELTS Lexical Resource + апгрейд слов | `{paragraph, targetWords[]}` |
| `POST /api/ai/speaking` | оценка фразы/произношения | `{word, text}` |
| `POST /api/ai/smart-card` | собрать карточку из «умного поиска» | `{rawWord}` |

Все ответы — `application/json`, gzip, примерно ≤2КБ. Промпт системный на английском, требуем строгий JSON-контракт, `temperature=0.2`.

### Продукт-решения по фичам
- **Мультиперевод → облако тегов**: `/enrich` возвращает массив `translationTags[ru]` (5–8 вариантов для ключевых, 2–4 для простых), `synonyms[en]`, `collocations[]`, `registerTags[]`, `topic`.
- **Коллокации**: 3 на слово (`significant impact`, `statistically significant`, …).
- **Адаптивный SRS v2**: SM-2 (ease 2.5, интервалы 1→3→7→14→30 с ease-множителем) + множитель сложности из `difficultScore`. Ошибка → интервал сбрасывается, `lapses++`. Проблемное слово (ошибки ≥2 за 7 дней ИЛИ pace < 50%) → в «Проблемный список» и подсовывается каждый раунд до достижения точности 95%.
- **Контекст**: примеры генерируются по закреплённым темам IELTS (Environment, Education, Technology, Health, Society, Work). Проверка своих примеров → `check-example` с подсветкой ошибок (грамматика/стилистика) и бинарным OK (для прогресса).

## 5. Уровни мастерства 0–10 и Surprise Test

| Уровень | Стадия |
|---|---|
| 0 | Новое слово |
| 1–3 | Пассивное узнавание (перевод → слово) |
| 4–6 | Активное вспоминание (слово → перевод/вокал) |
| 7–9 | Использование в контексте (ИИ проверяет примеры) |
| 10 | **Выучено** |

Условия уровня 10 (как в ТЗ):
1. 5 верных ответов подряд с интервалом ≥7 дней;
2. ≥2 корректных примеров (подтверждены `/check-example`);
3. входной контекст правильный.

Выход из уровня 10: ежемесячный **Surprise Test** — если забыл (любая ошибка), слово падает на **уровень 6**. Слова уровня 10 не попадают в ежедневную зубрёжку.

## 6. UI/UX v2

### Экран «Учить» (StudyView v2)
- 2х-зональный макет (карта 50% / кнопки 50%), тёмная тема, thumb-zone.
- Верх: крупный перевод, кнопка аудио, тонкая полоса прогресса (`12/50`).
- Низ: две кнопки на всю ширину:
  - **🟥 НЕ ЗНАЮ** (левая 50%) → переворот карточки, показ ответа, фиксация ошибки, `level--`, «проблемное».
  - **🟩 ПРОВЕРИТЬ** (правая 50%) → если был ввод (голос/текст) — показ правильного ответа + диалог «Я угадал / Я ошибся»; нет ввода — просто переворот для самопроверки.
- Убрать: кнопку «Показать ответ», режим `spelling` отдельной кнопкой (остаётся как опция), мелкие контролы. Флип — плавная 3D-анимация (+ scale/opacity).

### Экран «Слова» (WordListView v2)
- Списки по 50 слов (`Список 1: Environment`, …).
- Фильтры: **Все / В процессе / Выученные (Ур.10) / Проблемные** (сегментированный пикер).
- Строка: слово, перевод, badges (уровень, проблемный), icon enrichment.

### Экран «Статистика» (StatisticsView v2)
- Прогресс-бар до целевого IELTS Band.
- График «Кривая забывания» (Swift Charts, ось времени из `AttemptRecord`).
- Топ-10 проблемных слов (по `difficultScore`/ошибкам).
- Данные генерируются локально (без сети), ИИ только калибрует модель сложности.

### Boosters
- **Writing Booster**: слово → поле абзаца Task2 → `/writing` → критерии IELTS Lexical Resource + подсветка, где заменить на «более крутое» слово (с вариантами из облака тегов).
- **Speaking Booster**: запись/распознавание речи (речевой ввод), отправим текст → `/speaking`; оценка естественности и произношения.
- **Экспорт Anki/Quizlet**: генерация CSV/текст «Список 50 слов».
- **Геймификация**: виртуальные Band: за каждые 100 слов уровня 10 → «Band 7.0», 200 → «8.0» и т.д. (прогресс на Статистике).
- **Умный поиск**: вставка слова → `/smart-card` → карточка создана, добавлена в список.

## 7. Офлайн и бюджет (бесплатно)

- Кэш AI-ответов на устройстве: enrich повторно не запрашивается (флаг `isAIEnriched`).
- Пакетные вызовы (до 25 слов за запрос) — меньше запросов.
- `AIBudget`: суточный лимит запросов/токенов, при исчерпании — молча офлайн-режим с существующими данными.
- Всё важное ядро (SRS v2, уровни, статистика, Surprise Test) — **без сети**.

## 8. Тесты (прирост к текущим 54 unit + 3 UI)

- SRS v2: переходы уровней 0–10, интервалы с ease, сброс при ошибке, проблемные слова, порог уровня 10.
- Surprise Test: корректный откат на уровень 6, месячная частота.
- Миграция: UserDefaults → SwiftData (level×2, целостность сидов).
- AIBudget: лимиты, кэш, офлайн-деградация.
- UI: новый флип-флоу, две кнопки, фильтры списков, графики.
