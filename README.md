# 500 Words — интервальное повторение для iOS

Нативное офлайн-приложение на SwiftUI для изучения 500 английских слов. Проект готов к открытию в Xcode и поддерживает iPhone и iPad.

## Требования

- macOS с Xcode 16 или новее (проект проверен в Xcode 26.6);
- iOS/iPadOS 17.0 или новее;
- для установки на физическое устройство — Apple ID в Xcode;
- для Ad Hoc, TestFlight и App Store — участие в Apple Developer Program.

## Быстрый запуск

1. Откройте `WordFlow500.xcodeproj`.
2. Выберите scheme `WordFlow500`.
3. Выберите iPhone/iPad Simulator или подключённое устройство.
4. Нажмите `⌘R`.

Для физического устройства:

1. Откройте target `WordFlow500` → **Signing & Capabilities**.
2. Выберите свою Team.
3. Замените `com.example.WordFlow500` на уникальный Bundle Identifier.
4. Оставьте **Automatically manage signing** включённым.

## Тесты

В Xcode нажмите `⌘U`. Scheme запускает:

- 54 unit-теста корпуса слов, переводов и примеров, SRS, профильного хранения, миграции, динамических списков, пакетного импорта, уведомлений, статистики, сессии, анализа ошибок и проверки ответов;
- 3 UI-теста вкладок, ручного перехода после ответа, обоих Picker, пакетного импорта, управления списками, профилей и напоминаний.

Команда для Simulator:

```sh
xcodebuild test \
  -project WordFlow500.xcodeproj \
  -scheme WordFlow500 \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro'
```

Если такого Simulator нет в установленном Xcode, замените `iPhone 17 Pro` на имя любого доступного iPhone Simulator.

## Что реализовано

- 500 встроенных слов с русскими переводами: пять списков по 100;
- 1 500 встроенных английских примеров употребления — по три для каждого слова;
- четыре режима: слово → перевод, перевод → слово, выбор из 4, написание по буквам;
- SRS-уровни 0–5 с интервалами 1/2/4/8/16/32 дней;
- случайные due-сессии и fallback для слов ниже уровня 5;
- работа над ошибками: неверный ответ сохраняется, слово возвращается через несколько карточек, исправленные ошибки считаются;
- встроенные переводы можно исправлять; пользовательские варианты и примеры сохраняются;
- отдельные вкладки «Учить», «Слова» и «Статистика»; на карточке дополнительные поля свёрнуты;
- пользовательские списки: создание, переименование и безопасное удаление с переносом слов;
- добавление отдельных слов и пакетный импорт строк в формате `word | перевод | пример`;
- несколько локальных профилей с полностью раздельными словами, прогрессом, ошибками, рисунками и настройками;
- несколько гибких напоминаний для каждого профиля: время, дни недели, список, сложные слова и цель занятия;
- нажатие на напоминание переключает нужный профиль и запускает занятие с заданным списком, фильтром и количеством слов;
- системное произношение `en-US` через `AVSpeechSynthesizer`;
- рисование пальцем/Apple Pencil через PencilKit;
- статистика, сложные слова, фильтры списков и поиск;
- светлая/тёмная тема и полупрозрачные Material-карточки;
- локальное Codable-хранилище в `UserDefaults`; рисунки хранятся отдельно от лёгких данных карточек;
- уровни, даты повторения, статистика, история ошибок, пользовательские тексты, рисунки и настройки переживают перезапуск;
- privacy manifest без сбора данных;
- App Store icon 1024×1024.

В режиме «Слово → перевод» встроенный русский ответ скрыт до проверки или нажатия «Показать ответ». Если у перевода указано несколько вариантов через запятую, проверка принимает каждый из них. Пользовательская правка всегда имеет приоритет и не заменяется при следующем запуске.

В режиме «Перевод → слово» автоматическое произношение не запускается, чтобы не раскрыть английский ответ. Кнопка динамика остаётся доступной как явная аудиоподсказка.

После текстового ответа, самооценки или выбора варианта карточка остаётся открытой: можно спокойно прочитать правильный ответ и три примера, затем нажать «Следующее слово». Автоматического переключения нет ни в одном режиме.

Неверный введённый вариант и его краткий анализ сохраняются в истории карточки. В текущей сессии слово возвращается до двух раз; если ошибка не исправлена, SRS снова предложит его по рассчитанной дате. Любая оценка сразу сохраняет уровень, дату, счётчики и историю — закрытие приложения не теряет уже выполненную работу.

При обновлении со старой версии существующие данные автоматически переносятся в профиль «Основной». Новые профили начинают со встроенных 500 слов и не видят прогресс других пользователей.

Разрешение на локальные уведомления запрашивается только когда пользователь сам включает первое напоминание. Если доступ запрещён, приложение сохраняет расписание выключенным и предлагает открыть системные настройки.

При удалении пользовательского списка его идентификатор не переиспользуется. Сохранённые напоминания на удалённый список безопасно переключаются на «Все списки», поэтому они не смогут случайно начать занятие по новому списку.

## Создание Archive и IPA в Xcode

Перед архивированием укажите уникальный Bundle ID, Team, версию и build number.

1. Выберите scheme `WordFlow500` и destination **Any iOS Device (arm64)** / **Generic iOS Device**.
2. Выполните **Product → Archive**.
3. В Organizer выберите созданный архив и нажмите **Validate App**.
4. Нажмите **Distribute App**.

Для App Store/TestFlight выберите **TestFlight & App Store** (или **Custom → App Store Connect**), затем Upload либо Export. Для Ad Hoc выберите **Release Testing**, включите автоматическую подпись и экспортируйте `.ipa`.

Ad Hoc-сборка устанавливается только на зарегистрированные устройства. При ручной подписи заранее нужны App ID, Apple Distribution certificate, зарегистрированные UDID и Ad Hoc provisioning profile. При автоматической подписи Xcode управляет профилем.

Официальные инструкции Apple:

- [Preparing your app for distribution](https://developer.apple.com/documentation/xcode/preparing-your-app-for-distribution)
- [Distributing your app for beta testing and releases](https://developer.apple.com/documentation/xcode/distributing-your-app-for-beta-testing-and-releases/)
- [Create an Ad Hoc provisioning profile](https://developer.apple.com/help/account/provisioning-profiles/create-an-ad-hoc-provisioning-profile/)

## Архив и экспорт через Terminal

Шаблоны из папки `Distribution` используют автоматическую подпись и Team из подписанного архива. Если в аккаунте несколько команд и Xcode не может выбрать нужную, добавьте в выбранный plist ключ `teamID` со значением вашей команды.

```sh
xcodebuild archive \
  -project WordFlow500.xcodeproj \
  -scheme WordFlow500 \
  -configuration Release \
  -destination 'generic/platform=iOS' \
  -archivePath build/WordFlow500.xcarchive
```

App Store Connect:

```sh
xcodebuild -exportArchive \
  -archivePath build/WordFlow500.xcarchive \
  -exportPath build/AppStore \
  -exportOptionsPlist Distribution/ExportOptions-AppStore.plist
```

Release Testing / Ad Hoc:

```sh
xcodebuild -exportArchive \
  -archivePath build/WordFlow500.xcarchive \
  -exportPath build/AdHoc \
  -exportOptionsPlist Distribution/ExportOptions-AdHoc.plist
```

Готовый файл будет находиться в выбранной папке экспорта. Подписанный IPA нельзя создать без сертификата и Team конкретного разработчика.

Неподписанный IPA можно получить из архива, созданного с
`CODE_SIGNING_ALLOWED=NO`. Такой файл предназначен для последующей подписи:
iOS не установит его напрямую на устройство.

Перед публикацией также заполните в App Store Connect описание, ключевые слова, возрастной рейтинг, ответы Privacy и скриншоты поддерживаемых устройств.

## Структура

```text
WordFlow500/
  App/           точка входа
  Data/          500 слов и локальное хранилище
  Models/        слово, настройки, сессия, режимы
  Services/      SRS и TTS
  Utilities/     маршруты и тема
  Views/         карточка, список, настройки, редактор, холст
WordFlow500Tests/
WordFlow500UITests/
Distribution/
```
